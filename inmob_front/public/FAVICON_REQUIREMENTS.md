# Favicon and Icon Requirements

## Required Icon Files

The following icon files need to be created and placed in the `/public` directory:

### Standard Favicons
- `favicon.ico` (16x16, 32x32, 48x48 - multi-resolution)
- `favicon-16x16.png` 
- `favicon-32x32.png`

### Apple Touch Icons  
- `apple-touch-icon.png` (180x180) - iOS Safari
- `apple-touch-icon-precomposed.png` (180x180) - Legacy iOS

### Android Chrome Icons
- `android-chrome-192x192.png` (192x192)
- `android-chrome-512x512.png` (512x512)

### Open Graph / Social Media
- `og-image.jpg` (1200x630) - Facebook, LinkedIn, etc.
- `twitter-image.jpg` (1200x630) - Twitter/X

## Design Specifications

### Brand Colors
- Primary: #0F766E (Teal)
- Background: #ffffff (White)

### Design Elements
- Simple, professional real estate icon
- Possibly a house/building silhouette
- Use the brand teal color as accent
- Ensure good contrast for small sizes

### Content for OG Image
- "Inmobiliaria" branding
- Tagline: "Propiedades en Venta y Alquiler"
- Property imagery or icons
- Location: "Avellaneda y Reconquista"
